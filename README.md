# Learning Java

Repositório de estudos e exercícios de **Java**.

## Sobre

Este repositório contém materiais, exercícios e projetos desenvolvidos durante o aprendizado da linguagem Java.

## Conteúdo

- Exercícios básicos de sintaxe
- Programação Orientada a Objetos (POO)
- Estruturas de dados
- Projetos práticos

## Objetivo

Registrar a evolução do aprendizado em Java, desde os conceitos fundamentais até projetos mais avançados.
